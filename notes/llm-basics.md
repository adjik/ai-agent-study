# LLM 基础认知笔记

> 创建日期：2026-08-07 | 阶段 0：环境与认知准备

---

## 1. 什么是 LLM（大语言模型）

LLM（Large Language Model）是一个**基于海量文本训练的神经网络模型**，核心能力是"给定一段文字，预测最可能的下一个词（token）"。反复预测下一个词 → 逐词生成 → 看起来"理解并回答"了问题。

你不需要深入理解 Transformer 架构的数学原理，但要知道几个关键事实：

- LLM **不是数据库**——它不"查找"答案，而是"生成"答案
- LLM **不是搜索引擎**——它没有实时信息（除非通过工具接入）
- LLM **不知道自己的知识边界**——它可能自信满满地胡说八道（幻觉）

---

## 2. Token（令牌）

**Token 是 LLM 处理文本的最小单位**，不是"字"也不是"词"：

- 英文：1 个 token ≈ 0.75 个单词（`Hello world` = 2 tokens）
- 中文：1 个汉字 ≈ 1.5-2 个 tokens（`你好世界` ≈ 4-6 tokens）
- 粗略估算：**1000 tokens ≈ 750 英文单词 ≈ 500-600 个汉字**

**为什么重要**：
- 模型按 token 数量计费
- 每个模型有上下文窗口上限（如 128K tokens）
- 输入 + 输出都在上下文窗口内

---

## 3. 上下文窗口（Context Window）

**模型一次能"看到"的最大 token 总量**。当前主流模型：
- DeepSeek-V3：128K tokens
- Claude 4（Fable/Opus/Sonnet）：200K tokens
- GPT-4o：128K tokens

上下文窗口 = 系统提示词 + 对话历史 + 用户输入 + 模型输出，全部加起来不能超过。

**类比**：上下文窗口 ≈ **内存大小**。超出就放不下，要么截断要么压缩。

---

## 4. 温度（Temperature）与采样参数

控制模型输出的**随机性/创造性**：

| 参数 | 范围 | 作用 | 典型设置 |
|------|------|------|----------|
| `temperature` | 0 ~ 2 | 越高越随机/有创意，越低越确定/保守 | 代码/数学：0；一般对话：0.7；创意写作：1.0+ |
| `top_p` | 0 ~ 1 | 核采样，只从概率累积到 p 的词中选 | 通常 0.9-1.0 |
| `max_tokens` | 整数 | 限制输出最大 token 数 | 按需设置，避免浪费 |

**核心原则**：需要精确/确定 → 低温度（0-0.3）；需要创意/多样 → 高温度（0.7-1.0）。

---

## 5. 幻觉（Hallucination）

**LLM 生成看起来合理但事实上错误的内容**。

常见表现：
- 编造不存在的 API、函数、数据
- 对模糊问题"脑补"细节然后当作事实输出
- 混淆不同来源的信息

**缓解手段**（后续阶段会深入）：
1. **提示词约束**：明确要求"不知道就说不知道"
2. **RAG（检索增强生成）**：先查知识库，再基于查到的内容回答
3. **结构化输出**：用 JSON Schema 约束输出格式
4. **事实校验**：让模型对关键信息自检或交叉验证

---

## 6. 指令遵循（Instruction Following）

LLM 的底层是"补全文本"，但经过 RLHF（人类反馈强化学习）训练后，能够**遵循指令**。

**写好指令的要点**（这是阶段 1 的重点）：
- 明确角色（"你是一个资深 Java 后端工程师"）
- 明确任务（"帮我审查这段代码的安全问题"）
- 明确格式（"以 JSON 格式输出"）
- 给出示例（Few-shot：给 1-3 个输入→输出范例）
- 指定边界（"不要猜测，不确定的标记出来"）

---

## 7. LLM 调用流程（一次对话）

```
用户输入（prompt）
    ↓
系统组合：系统提示词 + 对话历史 + 用户输入
    ↓
发送给 LLM API
    ↓
模型逐 token 生成回复（自回归）
    ↓
返回完整回复（或流式逐 token 返回）
    ↓
将回复追加到对话历史（维持多轮对话）
```

---

## 8. 关键要点总结

| 要点 | 一句话 |
|------|--------|
| LLM 本质是"下一个词预测器" | 不是知识库，不是搜索引擎 |
| Token = 计费 + 窗口的单位 | 学会计数和估算 |
| 上下文窗口是硬限制 | 输入 + 输出都在里面 |
| 温度控制随机性 | 精确用低温，创意用高温 |
| 幻觉是固有特性 | 需要系统性缓解，不能靠"提示词"完全消除 |
| 好的指令 = 好结果 | 角色 + 任务 + 格式 + 示例 + 边界 |
